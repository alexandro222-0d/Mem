# Лабораторная работа №1
## Программирование линейных алгоритмов — Вариант 2

### 1. Тема работы
Программирование линейных алгоритмов.

### 2. Цель работы
Изучить базовые типы данных в языке С/С++, операторы ввода/вывода данных
и правила подключения необходимых заголовочных файлов; научиться составлять
линейные алгоритмы с использованием основных математических функций; изучить
возможности среды разработки С++Builder и правила составления и отладки
программ в консольном приложении.

### 3. Постановка задачи (вариант 2)

Составить блок-схему линейного алгоритма вычисления арифметического
выражения для заданных значений и написать программу двумя способами:
1) с использованием стандартных функций ввода/вывода языка C (`scanf`/`printf`);
2) с использованием стандартных потоков ввода/вывода языка C++ (`cin`/`cout`).

Вид арифметического выражения:

```
        cbrt(5 + |x - y|^2)
u   =   -------------------   -  e^|x - y|
         sin(x^2) + z^y
```

Исходные данные для проверки:

| x | y | z | u (контрольное значение) |
|---|---|---|---|
| -3.06 | 0.61 · 10⁻⁴ | 0.08 · 10³ | -18.91469 |

### 4. Блок-схема алгоритма

```
                ┌────────────┐
                │   Начало   │
                └─────┬──────┘
                      │
                      ▼
              ┌─────────────────┐
        1     │  Ввод  x, y, z  │
              └────────┬────────┘
                        │
                        ▼
        2     ┌────────────────────────────────┐
              │ a = cbrt(5 + fabs(x - y)^2)     │
              └────────────────┬────────────────┘
                                │
                                ▼
        3     ┌────────────────────────────────┐
              │ b = sin(x*x) + pow(z, y)        │
              └────────────────┬────────────────┘
                                │
                                ▼
        4     ┌────────────────────────────────┐
              │ u = a / b - exp(fabs(x - y))    │
              └────────────────┬────────────────┘
                                │
                                ▼
        5             ┌──────────────┐
                       │  Вывод  u    │
                       └───────┬──────┘
                                │
                                ▼
                       ┌──────────────┐
                       │    Конец     │
                       └──────────────┘
```

### 5. Текст кода программы

#### 5.1 Способ 1 — стандартные функции ввода/вывода (файл `lab1_c.c`)

```c
#include <stdio.h>
#include <conio.h>
#include <math.h>

int main()
{
    double x, y, z, a, b, u;

    puts("\n\t x, y, z = ");
    scanf("%lf %lf %lf", &x, &y, &z);

    a = pow(5.0 + pow(fabs(x - y), 2), 1.0 / 3.0);
    b = sin(x * x) + pow(z, y);
    u = a / b - exp(fabs(x - y));

    printf("\n x = %.7g\n y = %.7g\n z = %.7g\n u = %f\n", x, y, z, u);
    puts("Press any key ... ");
    getch();
    return 0;
}
```

#### 5.2 Способ 2 — стандартные потоки ввода/вывода (файл `lab1_cpp.cpp`)

```cpp
#include <iostream>
#include <conio.h>
#include <cmath>

using namespace std;

int main()
{
    double x, y, z, a, b, u;

    cout << "\n\t x, y, z = " << endl;
    cin >> x >> y >> z;

    a = pow(5.0 + pow(fabs(x - y), 2), 1.0 / 3.0);
    b = sin(x * x) + pow(z, y);
    u = a / b - exp(fabs(x - y));

    cout << "\n x = " << x
         << "\n y = " << y
         << "\n z = " << z
         << "\n u = " << u << endl;
    cout << "Press any key ... " << endl;
    getch();
    return 0;
}
```

> Примечание. Заголовочный файл `<conio.h>` и функция `getch()` относятся
> к среде C++Builder (Windows). При компиляции и тестировании программы в
> Linux (например, компилятором `gcc`/`g++`) эти строки нужно убрать или
> закомментировать — они не влияют на вычислительную часть алгоритма.

### 6. Результаты тестирования программы

Входные данные: `x = -3.06`, `y = 0.61e-4`, `z = 0.08e3` (то есть `z = 80`).

Результат работы программы:

```

0.61e-4
0.08e3
```

Полученное значение (`u ≈ -19.038644`) незначительно отличается от
контрольного значения из таблицы вариантов (`u = -18.91469`) — расхождение
объясняется округлением входных данных в исходном задании; вид формулы и
порядок вычислений (кубический корень, синус, степень, экспонента) полностью
соответствуют условию варианта.
