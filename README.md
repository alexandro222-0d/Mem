# КЛИНОК — сайт-портфолио барбершопа

Одностраничный сайт вымышленного минского барбершопа «КЛИНОК».
Сделан как портфолио-работа: тёмный графит, тёплое дерево, оранжевый акцент,
крупная типографика и много движения. Без фреймворков и сборки — чистые
HTML, CSS и JavaScript, открывается двойным кликом по `index.html`.

## Что внутри

| Блок | Содержание |
| --- | --- |
| Первый экран | ч/б кадр мастера за работой, акцентная кнопка записи, счётчики, барберский столб |
| Манифест | принципы студии, вращающаяся печать, параллакс-коллаж интерьера |
| Услуги | шесть карточек с иконками, ценой и длительностью |
| Прайс | строки с превью-картинкой, всплывающей у курсора, цены в BYN |
| Работы | галерея с фильтрами и лайтбоксом |
| Каталог форм | переключатель силуэтов со сменой фото и текстовой «расшифровкой» |
| Мастера | четыре карточки, биография раскрывается при наведении |
| Отзывы | слайдер с перетаскиванием, автопрокруткой и точками |
| Запись | форма из четырёх шагов с маской телефона, проверкой полей и модалкой |

## Эффекты

Прелоадер со счётчиком и шторкой, кастомный курсор с подписями, магнитные кнопки,
тёплое пятно света за указателем, зерно поверх страницы, появление блоков по скроллу,
разбивка заголовков по словам, параллакс фотографий, бегущая строка, реагирующая на
скорость прокрутки, 3D-наклон карточек, подсветка под курсором, прогресс чтения,
полноэкранное мобильное меню с круговой маской.

Всё движение отключается при `prefers-reduced-motion: reduce`.

## Структура

```
index.html
assets/
  css/style.css      токены, секции, адаптив (три брейкпоинта)
  js/main.js         15 независимых модулей, без зависимостей
  img/               22 фотографии + CREDITS.txt
  fonts/             Oswald и Inter, подмножества latin + cyrillic
  favicon.svg
```

## Запуск

```bash
open index.html            # или любой статический сервер
python3 -m http.server 8000
```

Проверено в Chromium на 1440×900 и 390×844: горизонтальной прокрутки нет,
ошибок в консоли нет.

## Важно

Бренд, адрес, телефон, имена мастеров, цены и отзывы вымышлены. Город — Минск, телефоны в формате +375, цены в белорусских рублях.
Форма записи ничего не отправляет — это демонстрация интерфейса.
Источники фотографий и лицензии — в `assets/img/CREDITS.txt`.
