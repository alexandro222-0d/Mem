# Передача контекста: проект «Селлер с нуля»

Ты продолжаешь работу над TikTok-сериалом. Всё ниже уже решено с автором — не переспрашивай, а продолжай.

## Что это
Анимированный сериал «Селлер с нуля» про бизнес на Wildberries (сезон 1), во 2-м сезоне — Ozon.
Формат и рисовка взяты с референса @cenabiznesa08 («Сеть с нуля» / «Цена бизнеса»), но название,
герой и слоган свои — референс не копируем.

## Репозиторий
`alexandro222-0d/mem`, ветка `main`, всё в папке `wb-series/`:
- `PLAN.md` — полный план: разбор референса, решения, сюжет сезона 1, промт для аватарки.
- `scripts/s01e01.md`, `s01e02.md`, `s01e03.md` — сценарии серий 1–3 (таблица «озвучка → кадр» + текст для озвучки).
- `engine/` — движок видео (README внутри):
  - `player.html` + `lib.js` — кадры 9:16 в HTML/SVG (герой, Аня, комната, карточки с цифрами, штампы, пузыри);
  - `preview.js` — стоп-кадры всех сцен; `render.js` — сборка MP4; `music.py` — своя музыка и звуки;
  - `tts.js` — озвучка через API ElevenLabs (пока не используется, см. ниже).
- `episodes/s01e01.js` — сцены серии 1 (готовы). Серии 2 и 3 — только сценарии, сцен ещё нет.
- Видео, звук и `build/`, `assets/` в git не кладём (`.gitignore`). Готовые ролики отдаём автору файлами в чат.

Запуск: `python3 wb-series/engine/music.py wb-series/assets` (один раз), затем
`NODE_PATH=$(npm root -g) node wb-series/engine/render.js s01e01`. Без озвучки получается `build/s01e01/s01e01_draft.mp4`.

## Озвучка — как сейчас договорились
Автор озвучивает сам в **Syntx** (syntx.ai, подписка на его Google-аккаунте). Доступа к аккаунту у тебя нет,
API у Syntx не найдено, в аккаунт по кодам из почты не входим.
Процесс:
1. Даёшь автору текст серии одним блоком (раздел «Текст для ElevenLabs» в сценарии).
2. Автор генерирует в Syntx **один MP3 на серию** и присылает в чат.
3. Ты режешь его по фразам: распознаёшь речь (faster-whisper ставится через pip и работает; аудио
   подавать как numpy-массив, потому что встроенный декодер падает), находишь границы фраз,
   кладёшь куски в `build/<серия>/voice/NN.mp3` — `render.js` сам подгонит длину кадров под голос.
4. Собираешь `render.js` и отправляешь готовое видео автору.

Если автор всё же добавит `ELEVENLABS_API_KEY` и `ELEVENLABS_VOICE_ID` в окружение — можно озвучивать
напрямую через `engine/tts.js`.

## Что дальше
1. Получить MP3 серии 1 из Syntx → нарезать → собрать финал серии 1.
2. Сделать сцены `episodes/s01e02.js` и `s01e03.js` по сценариям (тем же движком).
3. Отрисовать аватарку (промт в PLAN.md, раздел 4) — генерирует автор.
4. Переделка старого аккаунта (ник, описание) — обсудить с автором.
